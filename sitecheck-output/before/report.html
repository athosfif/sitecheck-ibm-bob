SC-001 Imagem sem texto alternativo Severidade Alta Aberto
Arquivo / localização
linha 24 — <img src="hero.jpg">
Como reproduzir
Abra o arquivo com um leitor de tela ou valide em https://validator.w3.org. O atributo alt está ausente.
Evidência
<img src="hero.jpg"> sem atributo alt na linha 24.
Correção recomendada
Adicione alt com uma descrição útil da imagem, por exemplo: alt="Imagem principal do portfólio". Se a imagem for puramente decorativa, use alt="".
SC-002 Campo de formulário sem rótulo associado Severidade Alta Aberto
Arquivo / localização
linha 32 — <input type="email" id="email-input">
Como reproduzir
Inspecione o campo no DevTools: nenhum <label for> aponta para este id. Leitores de tela não anunciam um rótulo descritivo.
Evidência
<input id="email-input"> na linha 32 não possui <label for="email-input"> correspondente nem aria-label.
Correção recomendada
Adicione <label for="email-input">Endereço de e-mail</label> antes do campo, ou use o atributo aria-label diretamente no input.
SC-003 Link interno apontando para destino inexistente Severidade Média Aberto
Arquivo / localização
linha 17 — <a href="contato.html">
Como reproduzir
Clique no link ou abra contato.html a partir do diretório do site. O arquivo de destino não existe.
Evidência
<a href="contato.html"> na linha 17; arquivo esperado em demo-site/contato.html não encontrado.
Correção recomendada
Crie o arquivo contato.html ou corrija o href para um destino que existe.
