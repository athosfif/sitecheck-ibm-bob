SC-001 Image missing alternative text Severity High Open

line 29 — <img src="hero-art.svg">
How to reproduce
Open the file with a screen reader or validate it at https://validator.w3.org. The alt attribute is missing.
Evidence
<img src="hero-art.svg"> has no alt attribute on line 29.
Recommended fix
Add an alt attribute with a useful image description, for example: alt="Main portfolio image". If the image is purely decorative, use alt="".
SC-002 Form field missing an associated label Severity High Open
File / location
line 36 — <input type="email" id="email-input">
How to reproduce
Inspect the field in DevTools: no <label for> targets this id. Screen readers do not announce a descriptive label.
Evidence
<input id="email-input"> on line 36 has no matching <label for="email-input"> and no aria-label.
Recommended fix
Add <label for="email-input">Email address</label> before the field, or add aria-label directly to the input.
